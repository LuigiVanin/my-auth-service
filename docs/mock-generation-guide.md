# Mock Generation Guide

This document explains how to automatically generate mock implementations for Go interfaces using various tools.

## Why Auto-Generate Mocks?

Manual mock creation:
- ❌ Time-consuming and error-prone
- ❌ Requires updates when interfaces change
- ❌ Inconsistent implementation patterns
- ❌ Verbose boilerplate code

Auto-generated mocks:
- ✅ Generated in seconds
- ✅ Always in sync with interfaces
- ✅ Consistent and tested patterns
- ✅ Minimal maintenance overhead

## Recommended Tool: Mockery

**Mockery** is the best choice for this project because:
- Works seamlessly with `testify/mock` (already in use)
- Active development and community support
- Rich configuration options
- Generates clean, maintainable code

### Installation

```bash
# Install mockery globally
go install github.com/vektra/mockery/v2@latest

# Verify installation
mockery --version
```

### Configuration

A `.mockery.yaml` file has been created in the project root with configurations for all interfaces:

```yaml
with-expecter: true
testonly: false
outpkg: mock
dir: "."

packages:
  auth_service/app/modules/core/user/repository:
    interfaces:
      IUserRepository:
        config:
          filename: user.mock.go
  # ... more packages
```

### Usage

#### Generate All Mocks

```bash
# From project root
mockery --all
```

#### Generate Specific Interface

```bash
# Generate mock for IUserRepository
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --output=./tests/modules/mock

# Generate mock for ILoginService
mockery --name=ILoginService --dir=./app/modules/login/services --output=./tests/modules/mock
```

#### Generate Mocks for Package

```bash
# Generate all mocks in a package
mockery --dir=./app/modules/core/user/repository --all --output=./tests/modules/mock
```

### Generated Code Example

**Input** (`app/modules/core/user/repository/interface.go`):
```go
type IUserRepository interface {
    FindWhere(where entity.User, with ...string) (*entity.User, error)
    Create(user entity.User) (*entity.User, error)
}
```

**Output** (`tests/modules/mock/user.mock.go`):
```go
// Code generated by mockery. DO NOT EDIT.

package mock

import (
    entity "auth_service/infra/entities"
    mock "github.com/stretchr/testify/mock"
)

// MockUserRepository is an autogenerated mock type for the IUserRepository type
type MockUserRepository struct {
    mock.Mock
}

// FindWhere provides a mock function
func (_m *MockUserRepository) FindWhere(where entity.User, with ...string) (*entity.User, error) {
    _va := make([]interface{}, len(with))
    for _i := range with {
        _va[_i] = with[_i]
    }
    var _ca []interface{}
    _ca = append(_ca, where)
    _ca = append(_ca, _va...)
    ret := _m.Called(_ca...)

    var r0 *entity.User
    if rf, ok := ret.Get(0).(func(entity.User, ...string) *entity.User); ok {
        r0 = rf(where, with...)
    } else {
        if ret.Get(0) != nil {
            r0 = ret.Get(0).(*entity.User)
        }
    }

    var r1 error
    if rf, ok := ret.Get(1).(func(entity.User, ...string) error); ok {
        r1 = rf(where, with...)
    } else {
        r1 = ret.Error(1)
    }

    return r0, r1
}

// Create provides a mock function
func (_m *MockUserRepository) Create(user entity.User) (*entity.User, error) {
    ret := _m.Called(user)

    var r0 *entity.User
    if rf, ok := ret.Get(0).(func(entity.User) *entity.User); ok {
        r0 = rf(user)
    } else {
        if ret.Get(0) != nil {
            r0 = ret.Get(0).(*entity.User)
        }
    }

    var r1 error
    if rf, ok := ret.Get(1).(func(entity.User) error); ok {
        r1 = rf(user)
    } else {
        r1 = ret.Error(1)
    }

    return r0, r1
}

// NewMockUserRepository creates a new instance of MockUserRepository
func NewMockUserRepository(t interface {
    mock.TestingT
    Cleanup(func())
}) *MockUserRepository {
    mock := &MockUserRepository{}
    mock.Mock.Test(t)
    t.Cleanup(func() { mock.AssertExpectations(t) })
    return mock
}
```

### Workflow Integration

#### 1. After Creating New Interface

```bash
# Generate mock for the new interface
mockery --name=INewService --dir=./app/modules/new/services --output=./tests/modules/mock
```

#### 2. After Modifying Interface

```bash
# Regenerate mock for updated interface
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --output=./tests/modules/mock
```

#### 3. Before Running Tests

```bash
# Ensure all mocks are up to date
mockery --all

# Run tests
go test ./tests/... -v
```

### Makefile Integration

Add to `Makefile`:

```makefile
.PHONY: mocks

# Generate all mocks
mocks:
	mockery --all

# Generate mocks and run tests
test:
	mockery --all
	go test ./tests/... -v -race

# Clean generated mocks
clean-mocks:
	rm -rf ./tests/modules/mock/*.mock.go
```

Usage:
```bash
make mocks      # Generate all mocks
make test       # Generate mocks + run tests
```

### CI/CD Integration

Add to `.github/workflows/test.yml`:

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Set up Go
        uses: actions/setup-go@v4
        with:
          go-version: '1.25'

      - name: Install mockery
        run: go install github.com/vektra/mockery/v2@latest

      - name: Generate mocks
        run: mockery --all

      - name: Run tests
        run: go test ./tests/... -v -race -coverprofile=coverage.out

      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.out
```

## Alternative Tools

### 1. GoMock (Official Go Mock)

**Pros:**
- Official Google tool
- Well maintained
- Feature-rich

**Cons:**
- Different testing API (not testify)
- More complex setup
- Requires code generation comments

**Installation:**
```bash
go install go.uber.org/mock/mockgen@latest
```

**Usage:**
```bash
# From interface file
mockgen -source=app/modules/core/user/repository/interface.go -destination=tests/modules/mock/user_repo_mock.go

# From reflection
mockgen -package=mock -destination=tests/modules/mock/user_repo_mock.go auth_service/app/modules/core/user/repository IUserRepository
```

### 2. Moq

**Pros:**
- Very simple
- Fast generation
- Minimal code

**Cons:**
- Less features
- Smaller community

**Installation:**
```bash
go install github.com/matryer/moq@latest
```

**Usage:**
```bash
moq -out tests/modules/mock/user.mock.go app/modules/core/user/repository IUserRepository
```

## Best Practices

### 1. Keep Generated Code Separate

```
tests/modules/mock/
├── app.mock.go          # Generated
├── user.mock.go         # Generated
└── README.md            # Documentation
```

### 2. Add Generation Header

Mockery automatically adds:
```go
// Code generated by mockery. DO NOT EDIT.
```

This indicates the file should not be manually modified.

### 3. Version Control

**DO** commit generated mocks to git:
- Ensures reproducible builds
- Faster CI/CD (no generation needed)
- Easy to review changes

```gitignore
# Don't ignore mocks
# !tests/modules/mock/*.mock.go
```

### 4. Regenerate on Interface Changes

```bash
# After modifying IUserRepository
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --output=./tests/modules/mock

# Commit changes
git add tests/modules/mock/user.mock.go
git commit -m "Update mock for IUserRepository"
```

### 5. Document Custom Mocks

If you need custom mock behavior:

```go
// custom_user.mock.go
package mock

// CustomUserRepository extends MockUserRepository with helper methods
type CustomUserRepository struct {
    *MockUserRepository
}

func (m *CustomUserRepository) MockFindByEmail(email string, user *entity.User) {
    m.On("FindWhere", entity.User{Email: email}, mock.Anything).Return(user, nil)
}
```

## Troubleshooting

### Issue: Mock not generating

**Problem:** `mockery --name=IUserRepository` produces no output

**Solution:**
```bash
# Check interface exists
grep -r "type IUserRepository interface" ./app

# Use full path
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --output=./tests/modules/mock --outpkg=mock

# Enable verbose logging
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --log-level=debug
```

### Issue: Import path issues

**Problem:** Generated mock has wrong import paths

**Solution:** Update `.mockery.yaml`:
```yaml
packages:
  auth_service/app/modules/core/user/repository:  # Use full module path
    interfaces:
      IUserRepository:
```

### Issue: Mock doesn't match interface

**Problem:** Test fails with "unexpected method call"

**Solution:**
```bash
# Regenerate mock
mockery --name=IUserRepository --dir=./app/modules/core/user/repository --output=./tests/modules/mock

# Verify interface hasn't changed
git diff app/modules/core/user/repository/interface.go
```
